## 1.0

- First release.
- Send any BMP (1/4/8/24/32-bit, any size) to infrared e-paper shelf labels: scaling, Floyd-Steinberg dithering and red/yellow accent detection.
- Text mode and built-in test card.
- Add tags by typing only barcode digits 3-16, or import from an NFC chip (live read).
- Live on-screen preview before sending.
- Interface in Italian and English.
